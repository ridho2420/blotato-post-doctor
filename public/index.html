Blotato Post Doctor

Check a post submission and get a plain-language answer: what happened, why, and what to do next.

Mode

Sample mode uses example responses, not your real posts. No API key needed.

The postSubmissionId you got back when the post was created. Live mode reads the API key from the .env file on this computer; the key never reaches this page. Each check is one read-only request, with at least 10 seconds between checks of the same ID.
